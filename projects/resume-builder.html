Resume Builder

A resume builder with a live A4 preview, four templates, drag-to-reorder sections and PDF export, in plain TypeScript.

The problem

Most resume builders hide the PDF behind a sign-up, or show the result only after you finish the form. I wanted one where you see the real page while you type and can download it straight away, with no account.

What it does

  • Editor for 15 section types: employment, education, projects, skills with a level slider, languages, links, certificates, custom sections and more. Sections and the entries inside them can be dragged into order, renamed and deleted.
  • Live preview of an A4 page beside the form, scaled to fit, in one of four templates.
  • PDF export through an A4 print window with margins repeated on every page, so long resumes break cleanly.
  • Autosave to local storage a second after you stop typing, plus JSON export and import.
  • Phones get Edit and Preview tabs, and there's a light and dark theme.

Templates are pluggable

Each template is a single React component file. Adding one means creating the file and registering it in the template list; it then appears in the gallery and renders the same resume data. More templates are on the way.

How it's built

There's no UI framework. Each section is a TypeScript class on a shared Draggable base that handles the drag handle, drop placeholder, reordering and delete. Every edit notifies a pub/sub manager that debounces to one refresh a second after typing stops; the store saves the resume as JSON and the preview re-renders the chosen template with React's renderToStaticMarkup. A small router serves the gallery, the builder and a 404 page.
